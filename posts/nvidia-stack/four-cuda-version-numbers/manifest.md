# Asset manifest — four-cuda-version-numbers

Figures 1–6 and 8 are generated by `assets/_figs.py`, which is kept in the repository and is the
thing to edit for a correction: change the data in the function, re-run `python3 _figs.py <n>`,
and the `.html`, `.svg` and 2× `.png` are all re-emitted together. The cover is rebuilt with
`python3 _cover.py`.

Figure 7 is the one `mermaid` figure. Its editable source is `assets/fig-07-which-number.mmd`;
re-render it with:

```bash
npx -y @mermaid-js/mermaid-cli -i assets/fig-07-which-number.mmd \
    -o assets/fig-07-which-number.svg -b "#f5f5f5"
python3 -c "import pathlib,sys; sys.path.insert(0,'assets'); from _build import rasterize; \
h=pathlib.Path('assets').resolve(); \
rasterize(h/'fig-07-which-number.svg', h/'fig-07-which-number.png', 2110, 1337, scale=1)"
```

The rasterize call needs **absolute** paths; a relative path makes headless Chrome render its own
error page into the PNG, which is silent and looks like a successful build.

## Route gate

Six of the eight figures are grids or scaled positions rather than graphs, so the gate stops at
Q4: proportional widths, a real number line, or a grid of real values that Mermaid cannot place.
Figure 7 is the only genuinely graph-shaped content — a diagnosis with four parallel paths and
more nodes than hand placement can carry — so it takes the `mermaid` route and keeps its `.mmd`.
No paper figure is reused anywhere in this post, so the `source` route and its rights record do
not arise; the Source credit and Rights columns are therefore `—` throughout.

`wheelio.py` is shared verbatim with part 1's lab, which is deliberate: the compatibility thread
(parts 2, 6 and 16) is meant to use one set of helpers, and a reader who downloaded it once should
find the same file.

Upload each PNG and each lab file to its suggested key in the public MinIO `media` bucket. Then
write the resulting URLs to `urls.txt`, one per line in manifest order, and run:

```bash
python3 .claude/blog-forge/scripts/fill_urls.py \
  posts/nvidia-stack/four-cuda-version-numbers/ \
  posts/nvidia-stack/four-cuda-version-numbers/urls.txt
```

Set `Content-Type: text/x-python` on the `.py` lab objects, `text/plain` on
`expected-output.txt`, and `Content-Disposition: attachment` on all five lab objects so the
article links download rather than render.
