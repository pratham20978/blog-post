
## 11. WAL buffers and full-page writes: the first touch after a checkpoint costs a whole page

### Two identical updates, one right after a checkpoint

```sql

checkpoint;
select pg_current_wal_insert_lsn() as lsn0 \gset
update customers set country = 'US' where id = 4242;
select pg_current_wal_insert_lsn() as lsn1 \gset
```
