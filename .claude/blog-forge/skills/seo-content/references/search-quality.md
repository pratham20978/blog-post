# Search-quality brief

Capture:

1. Reader and exact task or question.
2. Primary intent: informational, navigational, commercial, or transactional.
3. Direct answer that can stand in the first 100 words.
4. Terms that need precise definitions, without prescribing repetition counts.
5. One original worked example, diagram, dataset, or implementation detail.
6. Questions the article must answer to be complete.
7. Relevant existing Canery pages to link, with the reason each helps.
8. Credible primary sources and what each supports.
9. Title, summary, stable slug, category, and four to seven honest tags.
10. What would make this page materially better than the current result set.

Do not create a post whose only distinction is wording. Consolidate overlapping intent into one stronger canonical page.
