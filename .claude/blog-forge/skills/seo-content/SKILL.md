# Search-led Content

Start from the reader's concrete problem, not a target keyword count. Identify one primary intent, the direct answer, prerequisite questions, a worked example, and the next useful internal page.

For a new post, hand the approved brief to `blog-authoring`. For an existing post, preserve the slug and canonical, inspect the full article, and propose the smallest useful changes. Put the direct answer in the early Insights block; use descriptive H2 headings; cite original sources for factual claims.

Reject keyword stuffing, doorway pages, fabricated freshness, mass-produced near-duplicates, and title changes that overpromise. Search optimization must improve the article for a human reader.

Read `references/search-quality.md` when preparing a brief or evaluating an optimization.
