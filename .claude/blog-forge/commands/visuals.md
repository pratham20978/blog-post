Use the **blog-visuals** skill for: $ARGUMENTS

If the post has no figure plan yet, produce one: for each figure record the section, the one thing it must communicate, the route, and a draft caption.

If the plan exists, build the figures. Mermaid source where the grammar supports it, then diagram-design redraw, then export SVG and PNG. Write `manifest.md`.

Once the article is final, also read `references/linkedin-handoff.md` and write
`assets/linkedin-prompts.md` plus `linkedin.md`. Do not generate the LinkedIn
bitmaps, upload assets, or post to LinkedIn.
